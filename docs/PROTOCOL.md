# 协议速查

来源：DeTong DP305P（`3533:5C32`，序列号 `DP305P-Y60870279`）真机逆向，
以及 `dz-print`（MIT）的参考实现。完整逆向记录见原工作区
`DeTong/REPORT.md`、`DeTong/analysis/ble.md`、`DeTong/dz-print/protocol.md`。

## 命令帧（USB / BLE 相同）

```
<group:u8> <type:u8> <varbytes(len)> <data...> <checksum:u8>
checksum = (~sum(frame[1:])) & 0xFF
varbytes: len < 192 -> 1 字节；192..16383 -> 0xC0|(len>>8), len&0xFF
```

## 打印命令（无长度/校验包装，原样连写）

| 字节 | 含义 |
|---|---|
| `1b 40` | 初始化打印参数，开始一张 |
| `1b 4a n` | 走 n 个空行 |
| `1f 2a nL nH data` | 打印 `nL\|nH<<8` 点的一行，MSB 在左，1=黑 |
| `1f 2b m n data` | 打印有 `m` 字节前导空白的行（压缩型） |
| `1f 2e k` | 重复上一行 `k+1` 次 |
| `0c` | 定位到下一张标签边界 |

## 用到的设置命令

| 命令 | 含义 | 本工具发送值 |
|---|---|---|
| `1f 42 01 <p>` | 纸型：`00` 小票 / `02` 不干胶 / `03` 卡纸 / `04` 透明贴 | `02` |
| `1f 43 01 <d>` | 浓度 0..14（人话 1..15） | `--darkness-1`，默认 `09` |
| `1f 44 01 <s>` | 速度 0..4（0 最慢） | `--speed-1`，默认 `02` |
| `1f 80 01 7f` | 解锁 > 0x80 的命令 | 固定发送 |

## 传输层差异

| | USB | BLE |
|---|---|---|
| 接口 | 接口 1，HID 中断 `0x02`/`0x82` | GATT `ff02` 写 / `ff01` 通知 / `ff03` 事件 |
| 包头 | 每条 64 字节报告 `1e <varbytes 负载长度> <负载>`（`1e` = HID Report ID） | 无包头 |
| 单包 | 62 字节负载 | 512 字节（MTU 515） |
| 流控 | 无需 | `ff03` 的 `01 01` 是每写一次的信用，窗口 8 最快 |
| 权限 | macOS 需 sudo | 免 root |
| 有效吞吐 | 快 | ≈ 4.9 KB/s（瓶颈在 BLE 模块 → 打印机串口） |

## 查询命令（`dzpost` 里用于状态读取）

| 命令 | 返回 | 实测（DP305P） |
|---|---|---|
| `1f 79` | 设备名 | `DP305P-Y60870279` |
| `1f 70` | 状态 | `00` = 正常 |
| `1f 71` | DPI | `01 2c` = 300 |
| `1f 72` | 打印宽度 / 纸宽 | `03 c0` = 960 点 / `03 84` |
| `1f 7c` | 软件版本 | `3.1.20260820` |
