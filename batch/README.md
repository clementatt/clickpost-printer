# 批量发货 CSV（クリックポスト まとめ申込 / Amazon 版）

`orders.json` を編集して、Shift-JIS の CSV を生成する：

```bash
dzpost csv build batch/orders.json -o batch/clickpost-4件.csv
dzpost csv validate batch/clickpost-4件.csv   # 再確認
```

生成された `clickpost-4件.csv` を クリックポスト の「まとめ申込」→
「ファイルを選択」にアップロードする。

## 官方规则（来自 clickpost.jp/create_csv_manual_amazon.pdf）

| 列 | 項目 | 規則 |
|---|---|---|
| A | お届け先郵便番号 | **必須** ハイフンなし半角7桁 / ハイフンあり半角8桁 |
| B | お届け先氏名 | **必須** 敬称を含めない、全角20 / 半角40 字以内 |
| C | お届け先敬称 | 「様」または「御中」 |
| D–G | お届け先住所1〜4行目 | いずれか必須、各行 全角20 / 半角40 字以内 |
| H | 内容品 | **必須** 全角15 / 半角30 字以内 |

- 文字コード **Shift-JIS**、CSV テキスト（Excel 形式は不可）
- **1 回のアップロードは 40 件まで**
- ヘッダー行は変更しない

`dzpost csv build` は上記を自動チェックする（桁数・敬称・文字幅・
Shift-JIS で表せない文字・40 件上限）。エラーがあると書き出さない。

## 注意

- 1〜4 行目は**同じお届け先**（サンプルラベルの実データ）の複製。
  4 件とも同じ宛先ならこのままでよい。別々の宛先なら `orders.json` を書き換える。
- 住所は「1行目」に全部入れても、4 行に分けてもよい（合計 40 幅/行）。
- 全角数字でも `dzpost` 側で半角に正規化するが、CSV を直接編集する場合は
  半角で入れること。
